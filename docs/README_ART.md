# README cover artwork

The current README uses `docs/assets/quotelock-cover-v2.png`, generated with the built-in image-generation tool for the QuoteLock brand. It is conceptual artwork, not an app screenshot or evidence of a physical product. All product screenshots remain the unchanged captures of the synthetic running prototype.

The original SVG banner is retained as a separate legacy asset. No additional plugin installation, model download or prototype dependency was required.

## Final generation prompt

```text
Use case: ads-marketing / stylized-concept.
Asset type: a premium panoramic GitHub README cover for the real project QuoteLock.
Create a striking, disciplined brand cover, ultra-wide 3:1 landscape (ideally 1536 by 512). It should look like an expertly art-directed technology design studio made it, rather than a stock cybersecurity banner.
Brand and content: QuoteLock is a synthetic evidence prototype for one rules-priced telecom bundle quote that becomes a verified order record. The motif is versioned paper records held together with a precise red locking clasp. This is conceptual artwork, NEVER an app screenshot.
Visual direction: a luminous warm-white architectural background; rich near-black typography; one saturated signal-red accent #E40000. Elegant, tangible studio macro photography mixed with extremely clean editorial typography. On the right, a single beautifully rendered sculptural object: three thin off-white document plates, staggered by a few millimetres to suggest quote versions, secured by one precision-machined red Q-shaped clasp. Subtle ink-like rules on the plates, no tiny fake writing, no currency amounts, no invented metrics. Precise cast shadows ground it; exquisite matte paper and satin red material. No generic floating shield, robot, circuit board, neon/glow, glass dashboard, grid overlay, sparkles, gradients behind text, confetti or people.
Composition: substantial negative space, wide open left half for large text, sculptural object in the right half, calm but boldly editorial, with a thin red line anchoring the very bottom. Keep all content away from the edges. Do not use boxed cards or a standard SaaS UI mockup.
Text must be exact, crisp and very legible at the small width of a README:
main oversized black wordmark: "QuoteLock"
secondary headline on two lines: "One quote." then "Every handoff."
small unobtrusive line: "Rules decide. The model only listens."
No other text, badges, numbers, logos or claims.
Typography: confident contemporary grotesk, carefully kerned, beautifully composed, no ornate font. Give the wordmark a genuinely distinctive custom feel while keeping QuoteLock spelled exactly. This is a clean professional open-source project cover, not a presentation slide.
```
